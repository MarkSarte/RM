Accelerate Revenue Partners static multi-page website.

Open index.html locally or upload the folder contents to a web server.

The site preserves a shared template-derived visual system while using a distinct page structure for each content type:
- Home: portfolio landing page
- Revenue Management: service stack, weekly operating process, service levels
- Revenue Audit: diagnostic checklist, review matrix, deliverables, pricing bands
- PriceLabs Management: tool-focused hero, configuration cloud, setup versus management comparison
- Case Studies: editorial case-study layouts with metrics sidebars
- About: story, team rows, principles
- Insights: featured editorial layout and article grid
- Contact: compact introduction with form-first conversion layout

The contact form is static and redirects to the supplied thank-you page. Connect it to your preferred form backend before production use.
